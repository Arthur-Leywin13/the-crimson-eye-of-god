# Security and Responsible Use

The Crimson Eye of God is intended for privacy-conscious research and self-audits of accounts you own or are authorized to review.

## Scope

- Use official APIs or public interfaces only where the platform permits the intended use.
- Respect platform terms, rate limits, robots policies where applicable, and user privacy.
- Do not bypass authentication, CAPTCHAs, access controls, blocks, or anti-abuse systems.
- Do not attempt to access private accounts, private messages, hidden contact details, or non-public data.
- Do not use this project to stalk, harass, impersonate, profile, or target people.
- A generated profile URL is only a candidate link. It is not proof that an account exists, belongs to a person, or is available.

## Reporting

Do not publish personal information in bug reports. For security concerns, open a minimal issue without credentials, tokens, private profile data, or personal data.
